# Билет 28. Замкнутая сеть массового обслуживания

## 1. Определение

**Замкнутая сеть СМО** - это сеть, в которой фиксированное число заявок постоянно циркулирует между узлами и не поступает извне.

Внешний входящий поток для такой сети отсутствует.

## 2. Особенности

В замкнутой сети число заявок `N` постоянно.

Если заявка завершила обслуживание в одном узле, она переходит в другой узел сети, а не покидает систему окончательно.

Поток в каждом узле зависит от состояния всей сети, поэтому анализ сложнее, чем для открытых сетей.

## 3. Примеры

Примеры замкнутых сетей:

- производственный цикл с фиксированным числом деталей;
- парк станков и ремонтная служба;
- вычислительная система с фиксированным числом активных задач;
- транспортная система с постоянным числом машин на маршрутах.

## 4. Методы анализа

Для замкнутых сетей применяют:

- метод анализа средних значений `MVA`;
- алгоритм Гордона - Ньюэлла;
- имитационное моделирование;
- численные методы.

Метод MVA позволяет находить средние времена ожидания, средние числа заявок в узлах и пропускную способность без полного перебора всех состояний.

## 5. Вывод

Замкнутая сеть СМО описывает систему с постоянным числом циркулирующих заявок. Она удобна для моделирования производственных, ремонтных и вычислительных циклов.
