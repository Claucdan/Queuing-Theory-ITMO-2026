# Билет 30. Методы анализа сложных сетей массового обслуживания

## 1. Зачем нужны специальные методы

Сложные сети СМО состоят из многих узлов, имеют маршрутизацию, возвраты, приоритеты, разные классы заявок и нестандартные распределения.

Для таких систем простых формул часто недостаточно.

## 2. Аналитические методы

Для марковских сетей применяются аналитические методы:

- уравнения трафика;
- теорема Джексона для открытых сетей;
- формулы для узлов `M/M/1` и `M/M/n`;
- стационарные вероятности состояний.

Если сеть удовлетворяет условиям теоремы Джексона, ее можно разложить на отдельные узлы и анализировать их по отдельности.

## 3. Численные методы

Для замкнутых сетей применяют:

- метод анализа средних значений `MVA`;
- алгоритм Гордона - Ньюэлла;
- расширенный MVA для более сложных случаев.

Эти методы позволяют найти средние длины очередей, времена пребывания и пропускную способность.

## 4. Имитационное моделирование

Если система слишком сложна для аналитического решения, строят имитационную модель.

Имитационное моделирование полезно, когда есть:

- произвольные распределения;
- сложные дисциплины обслуживания;
- приоритеты;
- ограничения ресурсов;
- зависимые потоки;
- нелинейные правила маршрутизации.

Модель многократно запускается, а результаты обрабатываются статистически.

## 5. Вывод

Для анализа сложных сетей СМО используют аналитические, численные и имитационные методы. Выбор метода зависит от структуры сети, распределений, дисциплин обслуживания и требуемой точности.
