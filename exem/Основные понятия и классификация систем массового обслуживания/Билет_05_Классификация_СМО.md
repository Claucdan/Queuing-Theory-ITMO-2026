# Билет 5. Классификация систем массового обслуживания

## 1. По числу каналов

**Одноканальная СМО** имеет один канал обслуживания. Пример - один кассир или один сервер.

**Многоканальная СМО** имеет несколько параллельных каналов. Пример - несколько касс, операторов или врачей.

Чем больше каналов, тем выше потенциальная пропускная способность, но тем выше затраты на содержание системы.

## 2. По длине очереди

**СМО с отказами** не имеет очереди. Если все каналы заняты, заявка получает отказ. В обозначениях Кендалла такая система имеет последний параметр `0`, например `M/M/1/0`.

**СМО с неограниченной очередью** допускает любое число ожидающих заявок. Пример обозначения - `M/M/1/∞`.

**СМО с ограниченной очередью** имеет конечное число мест ожидания. Если очередь заполнена, новые заявки теряются или получают отказ. Пример - `M/M/1/m`.

## 3. По типу входящего потока

В обозначениях Кендалла первая буква описывает входящий поток:

- `M` - марковский поток, то есть пуассоновский поток с экспоненциальными интервалами между заявками;
- `D` - детерминированный поток с фиксированными интервалами;
- `G` - поток общего вида с произвольным распределением;
- `E_k` - поток с распределением Эрланга порядка `k`.

## 4. По зависимости от состояния системы

**Открытая СМО** - входящий поток не зависит от состояния системы.

**Замкнутая СМО** - поток заявок зависит от числа заявок внутри системы. Например, в ремонтной системе новые заявки появляются только от конечного числа работающих машин.

## 5. Вывод

СМО классифицируют по числу каналов, длине очереди, типу входящего потока, дисциплине обслуживания и зависимости от состояния системы. Такая классификация помогает выбрать правильную математическую модель и формулы для расчета.
