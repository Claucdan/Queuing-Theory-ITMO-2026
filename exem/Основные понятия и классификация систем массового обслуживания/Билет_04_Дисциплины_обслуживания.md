# Билет 4. Дисциплины обслуживания

## 1. Определение

**Дисциплина обслуживания** - это правило, по которому заявки ставятся в очередь и выбираются из нее для обслуживания.

Дисциплина влияет на среднее время ожидания, справедливость обслуживания, вероятность отказа и качество работы СМО.

## 2. Основные дисциплины

**FIFO** - first in, first out: первым пришел, первым обслужен. Это самая привычная дисциплина, например очередь в кассу.

**LIFO** - last in, first out: последним пришел, первым обслужен. Пример - обработка верхней заявки из стека.

**Random** - заявка выбирается случайно. Такая дисциплина может использоваться в моделях, где порядок не принципиален.

**Priority** - заявки имеют приоритеты. Сначала обслуживаются более важные или срочные заявки.

**PS** - processor sharing: ресурс обслуживания делится между несколькими заявками одновременно. Пример - распределение процессорного времени между задачами.

## 3. Приоритетное обслуживание

Приоритеты бывают двух основных типов:

- **абсолютный приоритет** - заявка высокого приоритета может прервать обслуживание заявки низкого приоритета;
- **относительный приоритет** - текущая заявка дообслуживается, но следующей выбирается заявка с более высоким приоритетом.

Пример абсолютного приоритета - экстренный вызов скорой помощи. Пример относительного приоритета - VIP-клиент, которого обслужат следующим, но не будут прерывать уже начатое обслуживание другого клиента.

## 4. Вывод

Дисциплина обслуживания задает порядок работы с заявками. От нее зависит не только математическая модель СМО, но и практическое качество сервиса: справедливость, скорость, вероятность ожидания и удобство для разных групп заявок.
